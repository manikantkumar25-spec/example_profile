# Animated Engineering Student Profile Website

A responsive, animated single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Firefox or another browser.
3. For local development, use the VS Code Live Server extension.

## Personalize before publishing
- Replace `your.email@example.com` with your email.
- Update GitHub and LinkedIn links in `index.html`.
- Review the project descriptions so they accurately reflect your current project status.
- Add a resume PDF and link it from the navigation if you want a downloadable resume.
- Update the education year if needed.

No build step or package installation is required. Google Fonts are loaded online; the site still works with fallback fonts when offline.
